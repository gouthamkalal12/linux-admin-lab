# Shell Scripting Basics

## Simple Script

```bash
#!/bin/bash
echo "Hello World"
```

## Variables

```bash
name="Goutham"
echo $name
```

## User Input

```bash
read username
echo $username
```

## IF Condition

```bash
if [ $a -gt $b ]
then
 echo "A is greater"
fi
```

## FOR Loop

```bash
for i in {1..5}
do
 echo $i
done
```

## Check Disk Usage

```bash
df -h
```

## Check Memory Usage

```bash
free -m
```
