# Linux User Management

## Create User

```bash
useradd username
```

## Set Password

```bash
passwd username
```

## Check User Information

```bash
id username
```

## Lock User Account

```bash
usermod -L username
```

## Unlock User Account

```bash
usermod -U username
```

## Delete User

```bash
userdel username
```

## Delete User with Home Directory

```bash
userdel -r username
```
