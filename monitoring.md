# Linux Monitoring

## CPU Usage

```bash
top
```

```bash
htop
```

## Memory Usage

```bash
free -h
```

## Disk Usage

```bash
df -h
```

## Directory Size

```bash
du -sh *
```

## Running Processes

```bash
ps -ef
```

## System Uptime

```bash
uptime
```

## Load Average

```bash
uptime
```

## Check Logs

```bash
journalctl -xe
```

## Monitor Real-Time Logs

```bash
tail -f /var/log/messages
```
