# Linux Networking

## Check IP Address

```bash
ip addr
```

## Show Routing Table

```bash
ip route
```

## Test Connectivity

```bash
ping google.com
```

## Check Open Ports

```bash
ss -tulnp
```

## DNS Lookup

```bash
nslookup google.com
```

## Check Network Interfaces

```bash
nmcli device status
```
